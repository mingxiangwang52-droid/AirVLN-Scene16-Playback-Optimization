# Scene16 优化报告

## 基线问题

原始前端直接播放 AirSim `768x432` 预览帧，并尝试通过光流或前端逐帧方式提高观感。实际表现为清晰度不足、运动重影、建筑边缘扭曲和长视频卡顿。后处理锐化只能放大压缩噪声，不能恢复源帧没有记录的细节。

## 采用方案

1. 从 Scene16 稳定池中筛选严格成功轨迹。
2. 读取成功会话的 `trace.jsonl`，不重新运行模型。
3. 用 trace 中的每一步位置和记录动作重建航向，并在 AirSim 中离线设置位姿。
4. 以 `preview_0`、`1280x720`、JPEG 传输捕获源帧。
5. 以 H.264 CRF 17、8 fps 编码。
6. 前端优先使用完成的视频，保留 hold 播放作为确定性回退。

## 验证

- 严格成功记录：77 条。
- 高清回放完成：76 条。
- 空帧失败：1 条，已剔除。
- 高清样片：228 帧、1280x720、8 fps。
- 样片渲染 endpoint 与 recorded endpoint 完全一致。

## 限制

AirSim 渲染仍是画质上限；如果场景材质或光照本身缺失，超分辨率、锐化和插帧都不能可靠补回真实信息。当前方案优先保证轨迹正确、画面不扭曲、播放可持续。
